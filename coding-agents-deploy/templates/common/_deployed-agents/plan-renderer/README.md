# plan-renderer (deployed)

Renders this project's implementation plan + the implementer-owned
`progress.json` overlay into a single self-contained HTML file.

This directory ships exactly **one runtime script** – `bake.py`. It embeds
the HTML template, the renderer JS, and both stylesheets as Python string
constants. No siblings are needed; you can delete this README and bake.py
is still functional.

## Bake

The implementer and reviewer agents bake automatically after every write
to the plan or the progress overlay. To bake manually:

```powershell
python .deployed-agents/plan-renderer/bake.py --plan {{plan_path}}
```

Defaults: progress = `<plan>.progress.json` next to the plan; output =
`<plan>.html` next to the plan. Both are runtime artifacts that are
gitignored by default; the plan itself stays tracked.

The rendered output is fully self-contained – open it directly in any
browser. `file://` works; no server. Mermaid loads from jsdelivr CDN.

## Auto-refresh

The baked page has a top-right toggle: `off / 5s / 15s / 60s`. While the
agent re-bakes after each progress write, the open browser tab refreshes
on the chosen interval and shows the new state. Scroll position is
preserved across reloads.

## Schema

See `.deployed-agents/conventions.md` (`## Live progress overlay`) for the
`progress.json` schema and the implementer write-checkpoint table.

## Refreshing the renderer itself

`bake.py` is generated by `pack.py` in the source repo (not deployed) from
the editable HTML/JS/CSS source files. To roll out a renderer update, run
`pack.py` in the source repo and redeploy this directory.
